なぜ、伏せた一枚が
鉱山を制したのか。

産出量の異なる五つの鉱山に、同一の手札五枚から一枚ずつを伏せて置く。大隊は兵士を破り、病原菌はほとんどの札と相打ちとなり、その病原菌を偵察兵のみが制する。決着のつかなかった鉱山は次のラウンドへ積み増され、終盤に至るほど一枚の重みは増していく。

どんなゲーム

三すくみの五枚を、五つの鉱山へ。

手札は毎ラウンド 0〜4 の五枚に戻る。問われるのはただ一つ、いずれの札をいずれの鉱山に置くか、である。

01

大隊 > 偵察兵 > 病原菌 > …

原則として、数字の大きい方が勝つ。ただし 病原菌（0） はいかなる兵士とも相打ちとなり、その病原菌を破り得るのは 偵察兵（1） のみである。

  • 0 病原菌 Germs：偵察兵以外のすべての札と相打ち
  • 1 偵察兵 Scout：病原菌を破り、兵士に敗れる
  • 2 歩兵隊／3 機銃兵／4 大隊：数字の大きい方が勝つ
02

鉱山は毎ラウンド再生する

獲得された鉱山には、次のラウンドに同じ産出量の鉱山カードが一枚配り直される。💎5の鉱山を得ても、そこは次もまた💎5である。

  • 五つの鉱山は、左から 💎1・2・3・4・5
  • 盤上から鉱山が失われることはない
03

相打ちは積み増される

相打ちとなった鉱山にはカードが積み重なり、次のラウンドにさらに一枚が配られる。💎4の鉱山が相打ちならば、次は💎4が二枚で 8点 となる。

  • 病原菌で押さえた山は、そのまま自らの標的ともなる
  • 第3ラウンドまで決着しなかった山は、いずれの手にも渡らない
04

同一の手札、同一の盤面

双方の手札はまったく同じであり、運の介在する余地はない。残るのは、相手がいずれの山に何を置くか という読み合いのみである。

  • 自らの札は表向き、相手の札のみ伏せて進行する
  • 決定と同時に、左から順に公開される

あそびかた

操作は、手札を選ぶことのみ。

1手札のカードをクリックすると、左の鉱山から順に配置される
2置き直す場合は、その鉱山をクリックすれば手札に戻る
3五枚を置き終えたら「これで決める」。左から順に公開される
4強い札を出した側がダイヤモンドを獲得する。鉱山の上に WIN / LOSE / DRAW が示される
5相打ちの鉱山は積み増されて次のラウンドへ持ち越される。全3ラウンドで決着する

パソコンではクリック、スマートフォン・タブレットではタップで操作する。

対戦相手

卓の向こうに座る、五人の打ち手。

同じ作者のテキサスホールデム All in TEXAS と共通の五人である。「堅さ・攻め・仕掛け」の三つの値を本作向けに読み替えており、同じ盤面であっても、相手によって置き方は異なる。

堅実

ビエホ

山の価値に従い、強い札から順に置く。仕掛けはほとんど用いない代わりに、取りこぼしも少ない。

攻撃

ディアブロ

最大の山を大隊で奪いに来る。病原菌による妨害も多く、大きな山ほど戦局は荒れる。

ゆるい

ゴルド

置き方に一貫性を欠く。価値の低い山に大隊を投じることもあり、噛み合えば思わぬ失点を招く。

標準

ヴィニー

定石に忠実である。価値の高い山を病原菌で押さえ、そこへ偵察兵を合わせてくる。

気まぐれ

ロコ

同じ局面でも置き方が一定しない。読み切れぬ反面、こちらの仕掛けも通りやすい。

むずかしさ

やさしい／ふつう／むずかしい

やさしい では、鉱山ごとに相手の置く札の予想とその根拠が示される。 むずかしい では、相手はあなたの前ラウンドの置き方まで読んでくる。

つくり

HTML / CSS / JavaScript だけ。

フレームワークもビルドも用いない。app/index.html を開けば、そのまま動作する。カードの絵は一か所に集約しており、読み込めた場合にのみ用いられる。

絵の 差しかえ口app/index.html の CARD_TYPES に画像のパスを記すのみ。読み込めない場合は数字だけで遊べる。
相手の 思考planAssignment() ただ一つ。やさしいモードの予想は、同じ関数を乱数なしで実行した結果である。
保存何も保存せず、サーバーにも一切送信しない。
カードの絵画像生成AIに一枚のグリッドとして描かせ、tools/make_cards.py で切り分け、背景透過、512px化を施している。

よくある質問

疑問に答える

お金は かかりますか？

かからない。無料であり、広告も課金もない。

インストールは 必要ですか？

不要である。ブラウザで開くだけで遊べる。ホーム画面に追加すれば、アプリと同様に全画面で起動できる。

データは どこかに 送られますか？

送られない。得点も設定もその場限りで、保存すらしていない。

病原菌は 強いのですか？

勝つことはないが、ほとんど負けることもない。偵察兵にのみ敗れ、兵士とはすべて相打ちとなる。相手に渡したくない鉱山に置き、積み増して仕切り直すための札である。

引き分けた鉱山は どうなりますか？

カードが積み重なり、次のラウンドにさらに一枚が配られる。💎4の鉱山が相打ちならば、次のラウンドは💎4が二枚で8点となる。第3ラウンドまで決着しなければ、いずれの手にも渡らない。

2人で 対戦できますか？

現在はCPU対戦のみである。相手は五人から選べ、むずかしさも3段階を用意している。

原作は どこで 買えますか？

アナログ版は、いそのたかみ氏（鷹巣堂）がゲームマーケット2020春で発表したカードゲームである。詳しくは鷹巣堂のブログを参照されたい。
